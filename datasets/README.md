# Included validation dataset

`karate.edgelist` is the standard 34-node, 78-edge Zachary Karate Club graph
with one-based node IDs. `karate.truth` contains the two post-schism factions.
Run with the final `true` argument to enable one-based IDs.

The TKDE paper also evaluates Dolphins, US politics books, Amazon, and nine
LFR graphs. Their exact raw realizations and generator seeds are not included
in the paper PDF, so those must be supplied separately for exact table-level
reproduction.
